# Game limitations

- Campaign progress is not saved. Restarting or closing the game begins a new campaign.
- Basic Medicine, elemental ammunition and Metal Component can be crafted, but medicine use, elemental firing and component equipment are not implemented. Use Basic Ammo for the rifle and cleared-night bed rest for healing.
- Scenery chests, tools and supplies are decorative unless an interaction prompt is shown.
- Crop growth scales mature models; separate authored growth-stage model sets are not included.
- Character poses combine supplied animation with procedural adjustments. Extreme camera/attack angles may show hand clipping or foot sliding.
- Runner and Tank use tinted/scaled variants of the shared zombie model. The rescue sequence uses a simplified helicopter presentation.
- Web play requires a desktop browser with WebGL 2 and HTTP/HTTPS hosting. Click the game canvas to regain mouse control after it is released.

Supplied model and icon pack license metadata is unavailable; see [asset credits](ASSET_CREDITS.md).
