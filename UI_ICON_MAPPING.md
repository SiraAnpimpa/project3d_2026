Seed packets contain their harvest illustration. Elemental ammo uses shape markers as well as colour. Quantity and selection are separate overlays. Selection and volume controls use `assets/ui/icons/selected.svg`, `slider_knob.svg` and `slider_knob_active.svg`.

Shared health, stamina, enemy, workbench, rest, menu, close and settings symbols use supplied FREE version imagery. Button backgrounds use the supplied white button texture as a tinted nine-slice. The clock is project vector art; the menu landscape is a native game capture. See [asset credits](ASSET_CREDITS.md) for provenance.
