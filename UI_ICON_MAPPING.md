## Missing suitable assets

- Clock: new simple vector dial, because Alarm is a phone, not a clock.
- Basic Rifle / Basic Ammo: new small vectors in the existing item-art palette replace incorrect iron/copper display icons only.
- No new health, stamina, skull, workbench, rest, menu, lock, close or button icons are needed.
- Fonts: none supplied; retain Godot’s bundled font with a consistent readable size hierarchy.
- Menu background: unchanged copy of the existing `docs/map_final_cleanup/after/farmstead.png`, not a map edit.
- Frame/panel styling: reuse the supplied square button as the nine-slice texture; native thin borders provide selection/focus.

## Final implementation

14 light symbols plus the existing white button graphic are used. The button importer uses `process/size_limit=32`; the source PNG remains unchanged. Three spare helper symbols are available but not shown. All24 items have a mapping; override decisions affect presentation only. No source item/plant/recipe/weapon resource changed.
