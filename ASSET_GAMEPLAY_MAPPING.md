# Asset roles

Paths for supplied models are relative to `Asset/`.

| Role | Source / implementation |
|---|---|
| Somchai | `Post Apocolypse Pack.undefined-glb/Characters Matt.glb` |
| Normal, Runner and Tank | `Post Apocolypse Pack.undefined-glb/Zombie.glb`, with variant scene/data settings |
| Rifle | `Post Apocolypse Pack.undefined-glb/Rifle.glb` |
| Melee fallback | Supplied `Wooden Bat Barbed.glb` |
| Crops | Eight Nature pack models selected by PlantData; see [plant mapping](PLANT_VISUAL_ASSET_MAPPING.md) |
| Home and rest | Furnished Cabin scenery plus the Bed interactable |
| Farming | Authored soil plots plus crop wrappers |
| Workshop | Workbench interactable surrounded by supplied tools, logs and stock |
| Forest and boundaries | Supplied Nature trees, rocks, grass and bushes on authored terrain |
| Depot and roadside | Supplied containers, vehicles, debris and project-authored structures |
| Rescue | Clearing and `Low Poly Military Vehicles-glb/Helicopter.glb` |
| Item illustrations | Project SVG art under `assets/ui/items/`; see [icon mapping](UI_ICON_MAPPING.md) |

Visual scenery does not automatically imply a gameplay interaction. Supply boxes, tools, fuel and medical props are decoration; farming, crafting, equipment, combat and rest are provided by their dedicated services.
